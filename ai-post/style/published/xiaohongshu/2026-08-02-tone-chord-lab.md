# 不下载App，打开网页就给乐器校音

🔥 想给乐器校个音，居然得先下App、注册、再看着手机内存被塞满——就为确认一下空弦准不准，这代价也太大了。所以我做了个网页，浏览器一开，对着乐器吹或弹就校音，一个App都不用下。💻

起因挺普通：最近我在玩布鲁斯口琴。每天从家走到实验室那十几分钟，闲着也是闲着，就在路上练口琴，正好可以拿自己的步伐当节拍器。这段时间我主要练压音，可对新手来说，光靠耳朵根本分不清压出来的音是偏高、偏低，还是已经稳稳落在目标音上，没个工具看着真不行。🎵

尝试了好几个工具，都不满意，一般的校音App和网站都只认单音、识别不了和弦。而且我对手机会有洁癖，实在不想下载一个专门的校音App。于是我就让 claude code 做了个专门校音的网页，在家里电脑上能用，在路上手机也能开。


用法就三步，一次说清。📌 第一步，浏览器打开 tone.mingyangbao.site 。📌 第二步，点"启用麦克风"，在弹窗里选允许。📌 第三步，对着乐器吹或弹，实时频谱、音高、和弦、色度能量图，全跟着你的声音走。

最让我上头的是那个实时频谱。✨ 压音是连续滑音，校音App永远慢半拍；我这儿能量峰值一路跟着滑，再配上音名和cent偏差，压没压到点上，一眼就看清。吉他扫个和弦，它也能整块认出来。

校音器大多只听单音，一弹和弦就装死，要么随机锁一个音；我这个有十个和弦模板，弹下去整块识别，根音、组成音都给你标出来。嫌开麦麻烦？还能把本地录音拖进去分析，A4基准、噪声门都能调，界面还是中英双语的。

说个我的设计细节。⭐ 口琴泛音多，校音器老把G显示成D；我加了道次谐波惩罚，候选频率在1/2、1/3处有强峰就先降权，别再把泛音当基频。吉他、小提琴这些泛音复杂的乐器，跟着一起受益。

免费、开箱即用，音频全在本地、不上传，练琴隐私也握在自己手里。🎯 管你弹吉他还是吹口琴，快去试试。
